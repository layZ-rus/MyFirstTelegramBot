## 🚀 Как пользоваться ботом

Взаимодействие с ботом происходит через удобное меню с кнопками. Просто нажмите `/start`, чтобы начать.

### 1. 💵 Узнать стоимость
Нажмите на эту кнопку, чтобы посмотреть актуальный прайс-лист на услуги:
*   Создание лендингов.
*   Разработка Telegram-ботов на C#.
*   Написание парсеров данных.

### 2. 📋 Мои контакты
Здесь собраны все способы связаться со мной. Кнопка выдаст кликабельные ссылки на:
*   Мой профиль в Telegram.
*   Мой GitHub.
*   Профиль на фриланс-бирже Kwork.

### 3. 💱 Курс валют
Бот в реальном времени парсит данные с API Центробанка РФ и выдает актуальный курс доллара (USD) и евро (EUR) к рублю.

### 4. 🧠 Задать вопрос ИИ
Самая интересная функция! Бот переключается в режим нейросети (работает через OpenRouter API). 
*   Нажмите на кнопку.
*   Напишите любой вопрос (например, *"Как дела?"* или *"Напиши код на Python"*).
*   Бот ответит вам, используя возможности современных ИИ-моделей.

---

## ⚙️ Технические особенности

*   **Умное состояние:** Бот запоминает, что вы находитесь в режиме ИИ, и отвечает на все текстовые сообщения, пока вы не нажмете другую кнопку. Состояние сохраняется в базе данных, поэтому не сбрасывается при перезапуске сервера.
*   **База данных:** Для хранения профилей пользователей и их настроек используется SQLite + Entity Framework Core.
*   **Обработка ошибок:** Бот корректно обрабатывает ситуации, когда внешние API (валюты или ИИ) недоступны, и сообщает об этом пользователю.

## 🛠️ Инструкция по локальному запуску (для разработчиков)

Если вы хотите запустить бота на своем компьютере для тестирования или доработки, следуйте этой пошаговой инструкции.

### Предварительные требования
Перед началом убедитесь, что у вас установлено:
*   [Visual Studio 2022](https://visualstudio.microsoft.com/ru/) (с рабочей нагрузкой «Разработка классических приложений .NET»).
*   [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (обычно ставится вместе с Visual Studio).
*   [Git](https://git-scm.com/downloads) (для клонирования репозитория).

### Шаг 1. Клонирование репозитория
Откройте терминал (или командную строку) и выполните команду:

```bash
git clone https://github.com/layZ-rus/MyFirstTelegramBot.git
```

Либо скачайте проект как ZIP-архив через кнопку **Code** на главной странице репозитория.

### Шаг 2. Открытие проекта
Откройте Visual Studio, нажмите **«Открыть проект или решение»** и выберите файл `MyFirstTelegramBot.sln` в папке проекта.

### Шаг 3. Восстановление NuGet-пакетов
Проект использует сторонние библиотеки. Они восстановятся автоматически при первой сборке, но лучше сделать это вручную:
1. Нажмите правой кнопкой мыши на проект в обозревателе решений.
2. Выберите **«Восстановить пакеты NuGet»** (Restore NuGet Packages).

В проекте используются следующие пакеты:
*   `Telegram.Bot` — для взаимодействия с Telegram API.
*   `Microsoft.EntityFrameworkCore.Sqlite` — для работы с локальной базой данных.
*   `Microsoft.EntityFrameworkCore.Tools` — инструменты для работы с БД.

### Шаг 4. Получение необходимых ключей
Для работы бота нужны два ключа:
1.  **Токен Telegram-бота:** Зайдите в Telegram, найдите `@BotFather`, создайте нового бота (команда `/newbot`) и скопируйте токен.
2.  **API-ключ OpenRouter:** Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai), зайдите в раздел **Keys** и создайте новый ключ (он начинается с `sk-or-v1-...`).

### Шаг 5. Настройка кода
Откройте файл `Program.cs` и найдите две строки в самом начале класса `Program`:

```csharp
private static readonly string BotToken = "ВАШ_ТОКЕН_ОТ_BOTFATHER";
private static readonly string OpenRouterApiKey = "ВАШ_КЛЮЧ_OPENROUTER";
```

Замените значения в кавычках на ваши реальные ключи, полученные на Шаге 4.

### Шаг 6. Запуск
Нажмите **F5** (или зеленую кнопку **▶ MyFirstTelegramBot** на верхней панели). 
В консоли появится сообщение:

```text
Бот @Ваш_Бот запущен (v4.0 - OpenRouter)
Нажмите любую клавишу для выхода...
```

Файл базы данных `bot.db` создастся автоматически в папке с исполняемым файлом.

### Шаг 7. Проверка
Откройте Telegram, найдите вашего бота по имени и напишите ему `/start`. Если появилось меню с кнопками — всё работает отлично!
