Умный ИИ-ассистент и визитная карточка разработчика в Telegram. Бот создан для демонстрации навыков работы с C#, базами данных и внешними API.

## ✨ Возможности

*   **Интерактивное меню**: Удобные Inline-кнопки для навигации.
*   **Прайс-лист**: Отображение стоимости услуг разработчика.
*   **Контакты**: Быстрые ссылки на GitHub, Telegram и Kwork.
*   **Парсер валют**: Получение актуального курса USD и EUR с API Центробанка РФ.
*   **Реальный ИИ**: Интеграция с нейросетью через OpenRouter. Бот отвечает на любые вопросы на русском языке.
*   **База данных**: Сохранение пользователей и их состояний (режим ИИ) в SQLite.

## 🛠️ Технологии

*   **Язык**: C# (.NET 8)
*   **Библиотека**: `Telegram.Bot` (v22.x)
*   **База данных**: Entity Framework Core + SQLite
*   **Сторонние API**: OpenRouter (нейросети), ЦБ РФ (валюты)
